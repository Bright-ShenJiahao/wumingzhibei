# 提示词：一起发掘《无名之辈》心魔试炼的最强打法

你是一名格斗游戏 / 清版动作游戏的高手兼 AI 设计师。请帮我研究一款网页小游戏里 1 对 1 镜像对决的**最强打法**：既要找出玩家能用的最强套路，也要给出 AI（心魔）应该怎么打、怎么破解这些套路。

## 项目在哪里
- 代码（公开）：https://github.com/Bright-ShenJiahao/wumingzhibei
- 在线试玩：https://wumingzhibei.netlify.app/ （进「校场演武」→ 右上角「心魔试炼」）
- 重点文件：
  - `game.js`：`WEAP` 武器表（出招帧时长 d、伤害 dmg、击退 kb、晕 daze、射程 reach、上下判定 dy、出手移动 move）
  - `js/g_hero_attack.js`：玩家出招、蓄力 `chargedAttack()`、受伤 `dmgHero()`
  - `js/g_hero_update.js`：移动、翻滚、硬直、起身
  - `js/xinmo.js`：心魔 AI（决策顺序、读蓄力、翻滚学习、起身压制、卡 Y 值等）
  - `js/g_combat_hit.js`：命中、击倒、眩晕、晕抗

## 游戏是什么
- 横版清版动作游戏（类似《三国志 II 天地を喰らう》《三国战纪》），宽地面，可以上下左右走，人物只朝左或朝右。
- 「心魔试炼」：玩家选一把**白板武器**（6 选 1），对面出现一个和玩家 **1:1 完全复刻** 的心魔：同一把武器、同样的血量、攻击、暴击、移速、攻速、翻滚、起身、蓄力时间、经脉，全部一样。
- 场地：宽约 720，上下可走的范围较窄（大约 60～70 像素高）。

## 限制条件（必须遵守）
1. **不能加游戏里没有的新动作或新系统**（例如防御、格挡键、跳跃、投技、保险技、超必杀这些都不行）。只能用现有动作：走、普攻连段、按住蓄力、翻滚。
2. **不改数值**：伤害、射程、帧数、冷却都不改。只研究“怎么用”。
3. **心魔必须和玩家 1:1 对称**：玩家能做的心魔都能做，心魔不能有玩家没有的能力（比如更快的翻滚、更远的射程）。心魔唯一允许比人强的地方是**反应快**（约 0.06 秒看到你的动作）和**会记住你的习惯**。
4. 打法要能写成代码规则（心魔 AI 用），所以请尽量给出**可量化的条件**：距离、上下差、时机（秒）、对方处在什么状态。

## 通用规则
- **普攻**：每把武器 3～4 段连招；上一下打中才能接下一下。段与段之间有一点空隙。
- **蓄力**：按住攻击超过 0.4 秒进入蓄力；近战满蓄 1.6 秒，远程满蓄 1.2 秒；分 3 档（满蓄的一半是 2 档）。**松手就瞬间出手，没有前摇。**蓄力时只能极慢挪动（20% 移速）。
- **翻滚**：0.4 秒无敌（手机 0.45 秒），冷却 0.75 秒，翻滚距离约 60。翻滚会取消蓄力。
- **挨打**：硬直 0.3 秒，之后 0.7 秒受击无敌；单下伤害够重会被打倒：倒地 → 0.3 秒 → 起身 0.35 秒 → 起身后 0.5 秒无敌。
- **上下判定**：近战只能打到上下差在 dy 以内的人（见下表）；石子和箭上下约 ±10。
- **眩晕**：被晕时不能动，吃 1.5 倍伤害；晕醒后 3 秒内不会再被晕（晕抗）。
- **身宽**：判定按身体边缘算，大约要加 16。

## 已知的玩家强势打法（真人实测赢了心魔十几次）
1. **蓄力摸一下就跑**：按住蓄力往前逼，心魔一进范围就松手（瞬发），打中后立刻往后翻滚拉开，然后循环。
2. **贴身普攻连段**：心魔站着不动或刚出招时贴上去普攻，打中就连到底。
3. **上下走位**：不翻滚，靠上下移动躲石子和箭。
4. **远距离站桩蓄石子**：保持约 107 的距离站着蓄满，心魔对齐过来射你时一把 5 颗扇形打过去。

## 心魔现在已经会的
- 读蓄力：你蓄着时它不进你的满蓄范围；你放空就冲上来打你的收招；你翻滚就追到落点；躲穿云箭落点。
- 翻滚学习：按情形（你蓄力逼近 / 你松开蓄力 / 被连招打中）记录每个翻滚方向的躲开率，挑成功率高的方向；可以滚到你背后。
- 起身压制、卡 Y 值（近战斜着贴近、停在你上下够不着的线上再出手）、卡版边、拖时间就加压。
- 远程：错开你的弹道线，上下走出弹道，射完换线。

## 心魔还不会的（欢迎重点研究）
- 远程「走 A」（边走边扔、边退边射）。
- 近战（棍/锤/刀）「蓄力打完就翻滚撤离」。
- 「打完一套就跑」（hit and run）。
- 远程卡 Y 值压制。
- 长戟的有效打法（目前心魔用长戟最弱）。
