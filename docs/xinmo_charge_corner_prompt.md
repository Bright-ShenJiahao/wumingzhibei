# 提示词：长戟、汉弓心魔为什么弱？是哪个机制导致的，怎么加强训练？（只读代码，请省 token）

**请省 token：** 不要运行训练、评测或浏览器；只读下面列出的代码段；回答 1500 字以内，多用表格和短句。

## 背景
《无名之辈》是一款横版清版网页游戏，「心魔试炼」是 1:1 镜像对决：玩家和心魔用同一把武器、同样的属性和规则。
心魔 = **规则层**（`js/xinmo.js` 的 `update()`）+ **神经网络**（只管中立时的走位、出手、翻滚、蓄力，用进化策略训练）。

## 硬性限制
1. 不加新动作或新系统：只有走、普攻连段、按住蓄力、翻滚。
2. 不改数值。
3. 心魔和玩家 1:1；心魔只允许反应快（固定 0.06 秒）和记住习惯，不能偷看按键。

## 关键规则（已核对代码）
- **近战蓄力**：按住 0.4 秒过门槛，满蓄 1.6 秒；**松手当帧结算伤害，没有前摇**。
- **锤子满蓄**：前方 80（加对方身宽），上下范围很宽（|dy| ≤ max(24, dx×0.7+14)），击倒。收招 0.16+0.09+0.30 = 0.55 秒，收招期间锤子不能移动。
- **长戟蓄力**：向前冲刺，满蓄冲 80，冲刺全程无敌；心魔把威胁距离估成约 130。
- **大刀蓄力**：前方 45、上下 45。
- **翻滚**：无敌 0.4 秒、冷却 0.75 秒，横向约 60、纵向约 42。
  - **翻滚会取消蓄力**，除非带了锦囊「藏势」。
  - **收招中可以翻滚取消**（`js/g_hero_update.js` 第 25～35 行）。
- **汉弓（11/01 新规则）**：取消蓄力箭数量；穿云箭伤害 1.1 / 1.5 / 1.9，晕 0.5 / 0.65 / 0.8 秒。

## 玩家反馈
1. 锤子心魔虽然强，但**只要玩家一蓄力，心魔就翻滚**；玩家蓄着往前逼，心魔一路后退，被**逼进墙角压死**。
2. 大刀心魔也被吐槽弱：玩家一蓄力，它就退开不敢接近。

## 我读代码找到的原因（请核对）
`js/xinmo.js` 里搜索 `if (s.charging && hw)` 那一段（约第 676～710 行），以及 `smartRoll()`（约第 313～340 行）：
1. 玩家蓄力时，有三条规则都会触发翻滚：
   - 离玩家不到 60 就滚；
   - 玩家蓄着朝它走来就滚；
   - 在玩家满蓄范围内就往后滚。
2. 后退都是**直线往后**，所以会被一路赶到墙边。
3. 到了墙角：
   - 「往后滚」被禁止；
   - 「从玩家身边滚过去」要求离玩家不到 75，锤子满蓄范围大，这条用不上；
   - 只剩上下滚，可落点仍在锤子扇形里，落地有约 0.35 秒空档，正好被打。
   - 「站在满蓄范围外等」的目标点被墙挡住，结果就是贴墙站着。

## 最新训练结果（11/01，新汉弓规则，累计 22.9 万局）
每把武器 35 局，对手是正常强度的测试玩家：

| 武器 | 规则版 | 网络版 | 结论 |
|---|---|---|---|
| 棍 | 14 胜 0 负 | 25 胜 0 负 | 用网络 |
| 锤 | 11 胜 1 负 | 28 胜 0 负 | 用网络 |
| 大刀 | 15 胜 3 负 | 27 胜 2 负 | 用网络 |
| 长戟 | 14 胜 9 负 | 14 胜 5 负 | 提升不显著，仍用规则 |

上一轮分项评测里：

- 汉弓对「蓄着逼近」时，心魔掉 89% 血、玩家只掉 15%；
- 大刀、锤子对各种蓄力型对手大量超时，双方都不进攻。

## 训练是怎么做的（请重点看）
- 训练脚本：`tools/xinmo_rl/selfplay.cjs`（14 种测试玩家写在 `PAGE_FN` 的 `__runEp` 里）。
- 方法：进化策略，每代 16 组扰动 × 4 局，σ=0.05，学习率 0.03；一局最长 30 秒，不画画面加速跑。
- 奖励：赢 +1 / 输 −1，另加换血 ×0.25；超时额外 −0.1。
- **6 把武器共用同一个网络**（一个 `heads.human`），按武器分别评测，决定这把武器是否启用网络。
- **网络输入 37 维，没有「是哪把武器」的信息**，只有一个「是否远程」：长戟和棍、汉弓和石子对网络来说完全一样（见 `js/xinmo.js` 的 `netFeatures()`）。
- **网络只有 8 个动作，每 0.12 秒选一次**（`netMove()`）：
  - 0 站着；1 走到攻击距离（远程固定走到离你 100）；2 后退 40；3 对齐你的上下位置；4 上下错开 30；5 出手；6 翻滚（方向由规则层的 `smartRoll` 挑）；7 蓄力。
- **网络只管中立走位**：躲招、起身、读蓄力、被逼墙角这些都由规则层先处理，网络管不到。
- 本次训练可以设重点武器：长戟、汉弓、大刀被抽到练习的机会是其他武器的 3 倍。结果大刀明显变强，长戟和汉弓没变强。

## 我们打算的改法（请评价）
1. **不直线后退，往场中间绕**：离墙 150 以内，玩家蓄力逼近时，斜着往场中间绕，不让自己被赶进去。
2. **真贴墙时**：离玩家不到约 48 就往玩家身后滚（锤、棍、刀的蓄力只打前方）；48～96 之间滚哪边都会挨打，就用第 3 条。
3. **一起蓄力**：心魔也按住蓄力，站在满蓄范围边缘等。
   - 玩家踏进范围 → 心魔先松手（双方范围一样，心魔只赢在 0.06 秒反应）；
   - 玩家放空 → 心魔往前蹭 15～20 再松手，抓 0.55 秒收招；
   - 概率随局内玩家蓄力频率变化（比如 50～70%），不能每次都蓄。
4. **少滚多走**：玩家蓄力时，只在「离得不到 60」或「学到你快松手」时才滚。
5. **先做表现差的**：长戟做「一起蓄力，等你进约 130 就冲」+「往场中间绕」；汉弓只做「往场中间绕」，不做对蓄。
