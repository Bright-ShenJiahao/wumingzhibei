# 提示词：为什么心魔拿长戟、汉弓偏弱？请分析训练数据并给出改法

## 背景
《无名之辈》的「心魔试炼」：玩家选一把白板武器，对面是 1:1 镜像的心魔（同武器、同属性、同规则）。
心魔 AI = **规则层**（`js/xinmo.js` 的 `update()`，读蓄力、翻滚学习、起身脱身、局内认打法等）+ **神经网络**（只管中立时的走位 / 出手 / 翻滚 / 蓄力，用进化策略训练）。网络按武器启用：现在棍、锤、刀用网络，石子、长戟、汉弓用规则版。

## 代码和数据
- 仓库：https://github.com/Bright-ShenJiahao/wumingzhibei ，**请看 `preview` 分支（最新）**
- 心魔：`js/xinmo.js`；玩家：`js/g_hero_attack.js`、`js/g_hero_update.js`；武器表：`game.js` 的 `WEAP`
- 训练和测试玩家：`tools/xinmo_rl/selfplay.cjs`（14 种测试玩家，都写在 `PAGE_FN` 的 `__runEp` 里）
- **训练报告**：`docs/xinmo_train/2026-10-31_17-rl.md`（最近一次训练，3.9 万局）
- **分项评测**（重点看）：`docs/xinmo_train/eval_breakdown_2026-11-01.md`，6 把武器 × 14 种测试玩家，每格 5 局，含胜负、超时、双方掉血比例

## 硬性限制
1. 不加新动作或新系统（只有走、普攻连段、按住蓄力、翻滚）。
2. 不改数值。
3. 心魔和玩家 1:1；心魔只允许反应快（固定 0.06 秒）和记住习惯。
4. 训练里的 2 倍强敌（`push2`、`charger2`）只做压力测试，不算正常表现。

## 现在的结果（每把武器 60 局正常对手）
| 心魔武器 | 版本 | 表现 |
|---|---|---|
| 锤 | 网络 | 最强：几乎不输，但对 charger / poke / fake / walkdodge 大量超时（双方都不进攻） |
| 石子 | 规则 | 强 |
| 刀、棍 | 网络 | 中上 |
| 汉弓 | 规则 | 偏弱 |
| **长戟** | 规则 | **最弱** |

## 请你回答
1. **长戟为什么弱？** 结合 `js/xinmo.js` 里长戟相关的逻辑（回马突计划 `m.weapon === 'halberd'` 那段、`m.dash`、裂伤 `hb`）和上面的数据，找出具体原因。尤其是：为什么被 push 和 oki 打得这么惨？为什么对蓄力型全是超时？
2. **汉弓为什么弱？** 尤其是对 poke：心魔掉 89% 血，玩家只掉 15%。汉弓心魔的普攻射击条件（`pinned`、`ready`、`lane`）、蓄力箭、穿云箭、走 A 有没有问题？
