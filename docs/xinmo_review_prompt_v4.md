## 硬性限制（不变）
1. 不加新动作或新系统：只有走、普攻连段、按住蓄力、翻滚。
2. 不改数值（例外：用户已经决定棍的晕是 0.8 秒、几率 15%/25%/0/50%）。
3. 心魔和玩家 1:1 镜像；心魔只允许反应快（固定 0.06 秒）和记住习惯。
4. 训练里的 2 倍强敌（`push2`、`charger2`）是用户要求保留的；它们只用于训练和另外列出的压力测试，**不参与上线判定**。
