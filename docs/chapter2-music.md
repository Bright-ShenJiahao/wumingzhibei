# 第二章音乐：《旌旗北望》

沿用第一关Web Audio合成与A羽五声（A、C、D、E、G），使用原创主题。战鼓为主，拨弦、埙式长音、低弦和短号构成战场层次。

| 状态 | 速度 | 编配 |
| --- | --- | --- |
| 行军/对白/路线选择 | 126 BPM，32小节循环 | 稀疏低鼓、桶鼓、低音持续音、简短拨弦主题 |
| 普通交战 | 126 BPM，32小节循环 | 密集战鼓、鼓花、拨弦八分脉动、短号呼应、低弦重音 |
| 首领交战 | 144 BPM，32小节循环 | 重鼓连击、更密的鼓花与较强低音，保持主题辨识度 |

## 状态与混音

- 第二章按`chapter2Run`与存活敌人判断交战，不依赖第一关的`lockR`。
- `T.chapterBoss`或`T.boss`的存活敌人触发首领层。
- 行军与普通交战共用排程时钟和主题位置，1.5秒交叉淡入淡出。
- 清空敌人后保留2.4秒交战状态，避免波次间短暂停顿频繁换曲；对白、选路等明确非战斗阶段直接回行军层。
- 开场对白时BGM压至平时45%，随原音量/静音控制恢复。
- 额外中频鼓皮共振照顾手机喇叭；总输出继续受原有压缩器与音量限制。
- 第一章曲谱、通用胜败短句不变。
