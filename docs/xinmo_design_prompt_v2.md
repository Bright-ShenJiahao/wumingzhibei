## 「心魔」是什么
- 横版清版动作游戏，宽地面，上下左右走，人物只朝左或右。
- 玩家选一把白板武器，对面出现一个 **1:1 镜像**：同武器、同血量、同属性、同规则。**这不是两个不同角色对打，而是“自己打自己”**：双方能做的事完全一样。
- 心魔唯一能比人强的地方：**反应快（约 0.06 秒）**，以及**会记住并利用玩家的习惯**。

## 硬性限制
1. 不加新动作或新系统（没有防御、跳跃、投技、保险技）。只有：走、普攻连段、按住蓄力、翻滚。
2. 不改数值（伤害、射程、帧、冷却、无敌时间都不改）。
3. 心魔不能拥有玩家没有的能力。
4. 设计要落到代码：写成可量化的条件（距离、上下差、对方状态、时间），并指出改 `js/xinmo.js` 的哪个函数。

## 已核实的关键规则（以代码为准）
- 受击：硬直 0.3 秒，**受击无敌 0.7 秒从挨打那一刻开始算**（硬直结束后还剩约 0.4 秒无敌）。所以一次交手通常只能打中 1 下，后面几段大多打进无敌里。
- 翻滚：无敌 0.4 秒，冷却 0.75 秒；横向约 60 像素，纯上下约 42。出招中也可以翻滚取消（双方都可以）。
- 蓄力：按住 0.4 秒过门槛；近战满蓄 1.6 秒，远程 1.2 秒；3 档。**松手瞬发，没有前摇**。蓄力时走路速度约 65%（弓约 55%）。
- 击倒：单下伤害够重才倒（≥2 × 击倒系数）；倒地 → 起身 → 起身后 0.5 秒无敌。
- 背击 ×1.5（从对方背后打），双方都有。
- 眩晕：被晕时吃 1.5 倍伤害；晕醒后 3 秒内不会再被晕。
- 锤子出招前冲：速度 80，持续 0.12 秒，实际只前冲约 9.6 像素。
- 6 把武器的参数都在 `game.js` 的 `WEAP` 里，蓄力形状在 `js/g_hero_attack.js` 的 `chargedAttack()` 里。

## 心魔现在已经会的（preview 分支）
- **决策顺序**（参考 SmashBot）：躲飞行物 → 反打（算你的收招还剩多久） → 读蓄力 → 防（你这一下会不会打中我） → 计划连招 → 骗招 → 神经网络走位 → 随机突进 → 拉距离。
- **读蓄力**：你按住超过 0.25 秒就当你在蓄；绝不进你的满蓄范围；你蓄着逼近或把它逼到场边，它就滚到你背后；你一松手它就滚；你放空了它抓你收招；你翻滚它追落点；它会躲穿云箭落点、躲蓄力石子的扇形。
- **翻滚学习**：按情形（你蓄力逼近 / 你松开蓄力 / 被连招打中 / 出招中遇险）记下每个方向的躲开率，按成功率挑方向。
- 起身压制、卡 Y 值（近战斜线贴近）、卡版边、拖时间就加压。
- 远程走 A：出手前对齐你的线，石子/箭离手后马上错开，太近就边打边退。
- 出招中遇险可以翻滚取消。
- **习惯记录**：被打后多久翻滚、爱往哪滚、起身是否马上出手、连段平均几段、蓄力比例、常保持的距离。
- **复盘**：它在哪种模式下最容易挨打（`risk()`），之后少做。
- **神经网络**：输入 29 维 → 64 → 64 → 8 种走位动作，只在 `netMove()` 这一层用。规则层优先，网络只决定“中立时往哪走”。用强化学习（进化策略）对 8 种测试玩家各打几万局；测试赢过规则版才启用，并且按武器分别决定用不用网络。

## 已知的真人打法（真人连赢心魔十几次）
1. 蓄力摸一下就跑：蓄着往前逼，心魔一进范围就松手，打中后马上往后滚，再循环。
2. 贴身普攻连段（之前有 bug，玩家打心魔连段接不上，已修）。
3. 不翻滚，靠上下走位躲石子和箭。
4. 在约 107 的距离站着蓄满石子，等心魔对齐过来。

## 请你设计（每一项都要能落成代码）
1. **怎么训练**：现在的强化学习哪里不对（奖励设计、测试玩家、网络只管走位是否太弱、输入特征够不够）？怎么改？要不要让心魔和自己打（self-play）、联赛式训练、加对手池？怎么用真人录像（模仿学习 / 先模仿再强化）？怎么判断训练出来的确实更强（评测方法）？
2. **怎么找玩家漏洞**：从录像和实时数据里，自动找出玩家**反复出现、能被惩罚**的习惯（例如“翻滚后 0.2 秒内必出手”“被打后总往下滚”“蓄满后必松手”）。给出数据结构、统计方法和触发阈值。
3. **怎么设计连招**：在“受击无敌 0.7 秒”的规则下，什么才算有效连招？打 1 下就撤、诱招再打、起身压制、背击、蓄力衔接，各自的时机表。每把武器分别写。
4. **怎么用翻滚**：什么时候滚、往哪滚、滚完接什么；翻滚冷却期间怎么保护自己；怎么骗对方翻滚再打它的落点。
5. **怎么用蓄力**：什么时候蓄、蓄几档、怎么不被打断（距离、对方状态、对方的翻滚冷却）；怎么用蓄力控制场地。
6. **怎么躲技能**：普攻、蓄力（瞬发）、长戟冲刺、穿云箭、扇形石子、连珠箭，分别怎么躲。哪些只能提前预判，哪些可以看见再躲。
7. **怎么用 Y 值**：卡 Y 值压制、错线躲弹、斜线接近；每把武器上下判定不同，Y 值怎么用。
8. **怎么在一局之内分析玩家**：开打后 10～20 秒内，怎么识别玩家属于哪种打法（例如“蓄力跑路型”“贴身型”“风筝型”），然后切换应对策略？给出特征、分类方法和切换规则。
