你上一轮帮我审查过心魔 AI。我按你们（GPT、DeepSeek）的建议改完了，请你**检查改得对不对、有没有引入新 bug、还有哪些不对称**。

## 硬性限制（不变）
1. 不加新动作或新系统：只有走、普攻连段、按住蓄力、翻滚。
2. 不改数值。
3. 心魔和玩家 1:1 镜像，心魔不能有玩家没有的能力；只允许反应快（固定 0.06 秒）和记住习惯。
4. 例外：训练时的「2 倍强敌」测试玩家（`push2`、`charger2`）是用户要求保留的，只在训练里用，游戏里没有。

### C. 局内分析（新）
- `styleReset()` / `styleTick()`：约 8 秒滑动平均，统计蓄力时间比例、贴身时间、平均距离、站着蓄的比例、松开蓄力后 0.4 秒内是否后撤、翻滚结束 0.25 秒内是否出手、心魔的飞行物飞过时你是走开还是滚开。
- 每秒判一次，分 5 型：蓄力摸一下就跑 / 站桩蓄力 / 贴身猛攻 / 走位躲弹 / 拉远风筝。同一型连判 2 次才切换，切换后 3 秒内不再切。
- 各型的应对：
  - 蓄力跑路型：站远 12，翻滚留着不用来进攻；
  - 贴身型：站近 6，被贴时 80% 滚到背后；
  - 风筝型：突进频率 ×2；
  - 走位躲弹型：石子多用散射；
  - 习惯“滚完必出手”（≥6 次、≥75%）：你朝它滚过来，它就先退。
- 复盘页会显示“本局认出你是 X 型（证据）”。

### D. 训练（`tools/xinmo_rl/selfplay.cjs`）
- 奖励：赢 +1 / 输 −1，换血 × 0.25 作辅助；出错的对局记 −2 并统计；一局最长 30 秒。
- 13 种测试玩家：push、human、kite、charger、ylane、poke、**fake（假蓄力骗）**、**walkdodge（只走位躲弹不滚）**、**rollatk（滚过来马上打）**、**camp（站桩蓄满等对齐）**、**switch（每 8 秒换打法）**、push2、charger2。
- 采样：武器 × 测试玩家全组合，按“越打不过越常练”加权。
- 网络输入从 29 维扩到 37 维（玩家翻滚冷却、是否在蓄、是否被晕、离左右墙、离中线、我上次打中你多久、我的翻滚冷却）。旧模型只读前 29 维；新增权重从 0 开始。
- 网络动作：翻滚随时可用（方向按翻滚学习挑），近战也能蓄力（在你走过来之前蓄得完才蓄）。
- 评测：每把武器 39 局，规则版和网络用同一批种子成对比较，**提升的单侧 95% 置信下界 > 0 才在这把武器上启用网络**。
