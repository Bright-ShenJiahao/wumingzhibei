## 背景
《无名之辈》「心魔试炼」：心魔是玩家的 1:1 镜像，同武器、同规则，只多了反应快（0.06 秒）和会记住习惯。
真人玩家反馈：**“心魔太喜欢滚了，我蓄力找 timing，在它翻滚落地时松手打它。”**
心魔的复盘也显示它学到了“你蓄力逼近时往上滚最管用（7 次躲开 100%）”“起身被你压时往上滚最管用”，于是一直往同一个方向滚。

## 规则要点
- 翻滚：前 0.4 秒无敌，冷却 0.75 秒；横向约 60、纯上下约 42。落地后到冷却好之前约 0.35 秒既不能再滚、也没有无敌。
- 蓄力：按住 0.4 秒过门槛，**松手瞬发**；蓄着能走（约 65% 速度）。
- 限制：不加新动作、不改数值、心魔和玩家 1:1。

## 已知问题（我自己的判断，请核对）
1. 翻滚是否成功，只看从开始滚算 0.7 秒内有没有挨打。落地后被抓往往超过这个时间，所以统计成“躲开 100%”，心魔会越滚越多。
2. 挑方向时总选成功率最高的那个，方向固定，落点好猜。
3. 能走开时也滚，翻滚用得太随便。
4. 滚之前没有检查“落点是不是还在对手满蓄的范围里”。

## 我打算这样改（请评价，并补充遗漏）
1. 能走开就不滚：先算走出对手攻击范围要多久，来得及就走。
2. 对手在蓄力时，落点还在对手满蓄范围内，就不滚，改成走开或上下错开。
3. 方向按成功率随机选，连续同一方向会降权。
4. 成功判定改成从开始滚到落地后空档结束（约 1 秒），落地被抓也算失败。
5. 局内识别“蓄力等落点型”：对手常在心魔落地时松手，就明显降低翻滚频率。
