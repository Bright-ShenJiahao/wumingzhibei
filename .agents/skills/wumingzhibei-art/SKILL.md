# 《无名之辈》美术接入与质感规范

这份规范来自项目里反复出过的错。**每一条都对应一次真实返工**，不要跳过。

## 0. 三条铁律

1. **做完必须亲眼看图再推送。** 跑通、不报错 ≠ 好看。每次改美术都要截图或出对照图，自己看一遍，确认没问题再提交。说"已完成"之前，先回答：我看过截图了吗？
2. **只改任务要求的东西。** 不顺手改别的数值、帧名、缩放；发现别的问题写在回复里告诉用户，由用户决定。
3. **拿不准就停下来问**，不要硬猜着做完。尤其是：素材张数/姿势数和预期对不上、比例看起来不对、要删别人的东西。

## 1. 世界坐标和比例（最常出错）

- 屏幕高度固定 300 世界单位（`M.viewH`），`PX = 0.4`：1 个精灵像素 = 0.4 世界单位。
- 人物精灵约 72～76 像素高，游戏里再乘 `TYPES[].scale`（喽啰 .86、刀手 .92、弓手 .92…）。**新兵种的 scale 要和同级小兵一致**，不确定就和喽啰对比。
- 道具/背景是手绘图，按 `art/props/meta.json` 的世界尺寸绘制。
- 场景里的门、窗、家具要和人物比例对得上：门高 ≈ 人高 × 1.2～1.3。换背景图时先算这个，不对就单独给这个场景的人物加缩放。
- **背景、人物、判定必须用同一套坐标换算。** 换图后的 cover 缩放/裁边，人物位置和判定区域要跟着同一个函数算，不能各算各的。
- 攻击判定要和图里武器实际够到的位置一致（避免"隔空打人"）。改了武器美术就重新量戟尖/棍梢位置（`tools/build_guanhai.py` 会打印戟尖坐标）。

## 2. 人物美术流程

1. Gemini 出绿底动作图（提示词用中文，见 `AGENTS.md`）。**图里绝不让 AI 写字、画长武器**：
   - 字：一律代码写（AI 写汉字必错，缩小后也糊）。
   - 长武器/旗杆：用"武器分离"——让 AI 画**空手但做握持姿势**的人，武器单独出图，代码按拳头位置贴上（参考 `tools/build_guanhai.py`、game.js 的 `BANNER_GRIP`）。拳头要再画一遍压在武器上面，否则看起来没握住。
2. 用 `tools/pixelize_sheet.py` 转像素（补帧用 `area` 或 `ref=帧名:高度`，保证和已有帧一样大；脱手的武器用 `strict` 丢掉）。
3. **跑 `python3 tools/contact_sheet.py 角色名`，打开输出图检查：**
   - 帧名和动作对得上（曾经出现过 fly1/fly2/land/down 整体错位一格）；
   - 和主角、喽啰比大小一致；
   - 脚底红十字踩在横线上；
   - 没有绿边、杂点、残缺、粘连到隔壁帧的东西。
4. 颜色：转像素的调色板不要太少。画面里大块单色（比如马的棕色）会把小块重要颜色（头巾黄、皮肤）挤掉——这种情况把调色板拆开或合并另一组帧的调色板（见 `build_guanhai.py`）。

## 3. 文字

- 汉代题材用隶书（旗帜：`tools/fonts/LinHaiLiShu-flag.ttf` 子集），界面用毛笔字（`art/fonts/result.ttf`，Ma Shan Zheng 子集）。
- **字要在高分辨率下写，再按设备分辨率缩放绘制**；不要先写进小像素图再放大（会糊）。
- 新增用到的字，记得字体子集要包含它们（`tools/build.py` 自动收集；隶书子集要手动重做）。
- 不要从 Google Fonts 在线加载（国内微信打不开），字体 base64 打包。

## 4. 质感清单（"没质感"基本都是漏了这些）

做任何界面/特效/新物件时逐条对照：

- **和背景同一个世界**：颜色从背景里取（土黄、暗褐、黄昏暖橙），不要用纯白、纯黑、电脑默认蓝灰。描边用"所在颜色压暗"而不是纯黑。
- **像素图不能平滑放大**：人物用整数倍或 `imageSmoothingEnabled = false`；手绘图和贴图才开平滑。
- **有体积**：明暗至少三层，光从左上来；地上的东西要有接地阴影（但别和原图自带的影子叠两层——叠了会像浮在空中）。
- **有动态**：会动的东西加缓动（ease-out）、轻微回弹；布料/旗/火要有持续的小摆动；同类物件的动画相位错开，不要整齐划一。
- **有反馈**：命中有顿帧/震屏/闪白/碎屑，拾取有飘字和音效，按钮按下要下沉变暗。
- **UI 不像网页弹窗**：不用纯色矩形 + 系统字体。用卷轴/木牌/印章等素材，弹出时背景压暗 + 暗角，入场有动画。
- **层级正确**：按 y 排序绘制；武器/旗在身后的画在身后，手压在杆上；血条、提示不要压住重要文字或人脸。
- **手机横屏、电脑都看一遍**：文字不能超出边框，按钮不被 Netlify 标志或手势条挡住。

## 5. 代码层面的老坑

- `ASSETS`、`BG` 是 `const` 声明，**不在 `window` 上**：写 `ASSETS.xxx`，不要写 `window.ASSETS`（配音和登录背景都在这里栽过）。判断是否存在用 `typeof ASSETS !== 'undefined'`。
- `index.html` 是生成文件：只改 `game.js` / `js/*.js` / `index.src.html` / `tools/`，然后 `python3 tools/build.py`。合并别人提交后有冲突，**重新生成**，不要手动合并 index.html。
- 文件统一 LF 换行（`.gitattributes` 已设置）。
- 新功能尽量写成 `js/` 下独立模块；`game.js` 里只加一两行调用，调用前判断模块是否存在。
- 素材体积：照片类/手绘图转 WebP，像素图走 build 里的 256 色压缩；不要把几百 KB 的 PNG 直接打包。

- [ ] 改人物：跑过 `tools/contact_sheet.py` 并看过图。
- [ ] 进游戏截图看过：比例、层级、颜色、文字清晰度。
- [ ] 手机横屏尺寸看过一次。
- [ ] 判定范围和美术对得上。
- [ ] 回复里写清楚：改了什么、哪里还不完美、需要用户补什么图。
